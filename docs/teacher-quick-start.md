# Teacher Quick Start

## 1) Sign in

- Open the School Cloud URL.
- Sign in using your assigned account.

## 2) Upload a file

- Click `Upload` in the top bar.
- Select a file.
- Fill metadata prompts:
  - Title
  - Tags (required)
  - Student admission number (required for portfolio uploads)
  - Optional description

## 3) Find files later

- Use the top search bar.
- Navigate to the relevant module page:
  - Student Portfolios
  - Staff Resources
  - Media Library
  - Academic Tools

## 4) Download files

- Use the download button on file cards/lists.
- Download URLs are time-limited and secure.

## 5) Common mistakes to avoid

- Uploading without meaningful tags.
- Portfolio uploads with wrong student linkage.
- Saving media without proper approval state.
